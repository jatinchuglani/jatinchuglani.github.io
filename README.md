# Portfolio

Static site built with Astro. Hosted on GitHub Pages.

- Edit name, links and builds: `src/data/site.ts`
- Add a case study: new `.md` file in `src/content/work/`. Work in progress goes in `src/content/work/drafts/` (git-ignored, preview-only). Move a file up one folder to publish it.
- Preview: `npm run dev`. Build: `npm run build`.
- Deploys on push to `main`.
